# Komponentensatz-Vorlagen

**Format:** Vorlagenpaket · **Lizenz:** CC BY-SA 4.0

Ein Komponentensatz ist ein Schnappschuss mehrerer Komponenten, etwa eine Virtualisierungsumgebung mit Hosts, Verwaltung, Speicher und Sicherung oder ein Internetportal mit zentraler Anmeldung, WAF und Datenbank. Anwenden erzeugt neue, unabhängige Komponenten.

## Teilen lohnt sich zum Beispiel für

- Virtualisierungsumgebung im eigenen Rechenzentrum
- Standard-Stack für Portale mit externem Zugriff
- Fachverfahren mit Datenbank, Dateiablage und Sicherung
