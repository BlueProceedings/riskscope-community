# Komponentenvorlagen

**Format:** Vorlagenpaket · **Lizenz:** CC BY-SA 4.0

Der typische Fall ist die virtuelle Maschine im eigenen Virtualisierungscluster. Eine Komponentenvorlage enthält Beschreibung, Kategorie, Abhängigkeiten, Betriebsmodell und Statusvorbelegungen. Name und Standort werden beim Anlegen neu festgelegt; Dienstleister erscheinen nur als Archetyp, nie mit Namen.

## Teilen lohnt sich zum Beispiel für

- Virtuelle Maschine mit Linux oder Windows Server, gehärtet, gesichert und überwacht
- Firewall-Cluster, Mail-Gateway, Identitätsdienst
- Typische Cloud-Dienste mit klarer Aufteilung der Verantwortung
