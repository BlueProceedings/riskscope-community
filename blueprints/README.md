# Blaupausen

**Format:** OSCAL-Profil · **Lizenz:** CC BY-SA 4.0

Eine Blaupause ist eine wiederverwendbare Anforderungsauswahl für eine Art von Informationsverbund: Ausschlüsse mit Begründung, zusätzliche Anforderungen und Parameterwerte. Sie ist an eine Katalogversion gebunden; bei einem neuen Katalogstand zeigt RiskScope, was sich ändert.

## Teilen lohnt sich zum Beispiel für

- Branchentypische Auswahl, etwa für Bürgerportale einer Kommune, Kundenportale von Stadtwerken oder Praxisverwaltungen
- Begründete Ausschlüsse, die andere nachvollziehen und übernehmen können
- Parameterwerte, die sich bewährt haben, zum Beispiel Prüfintervalle und Fristen

## Stand

Noch keine Einträge. Einreichungen starten mit der ersten Version von RiskScope (geplant Januar 2027). Bis dahin:
Wünsche und Ideen gern in den [Diskussionen](https://github.com/BlueProceedings/riskscope-community/discussions).
